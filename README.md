# Лабораторная работа №1

Автор: Роман Хадралиев

Консольное приложение на Kotlin для проверки прав доступа пользователей
к иерархическим ресурсам. Все данные (пользователи, ресурсы, правила
доступа) хранятся прямо в коде, пароли — в виде SHA-256-хэшей с солью.
Программа работает тихо и сообщает результат через код возврата; вывод
на экран возможен только при запросе справки.

---

## Требования

- JDK 11 или выше;
- компилятор Kotlin `kotlinc`, доступный в `PATH`;
- jar-файл `kotlinx-cli-jvm-0.3.5.jar`, скачанный в каталог `lib/`.
  
## Сборка

```bash
./build.sh
```

Скрипт компилирует `src/Main.kt` вместе с `kotlinx-cli` и упаковывает
результат вместе с Kotlin runtime в `app.jar`.

---

## Запуск

```bash
./run.sh --login <логин> --password <пароль> --action <действие> \
         --resource <путь> --volume <объём>
```

Пример:

```bash
./run.sh --login alice --password qwerty --action read --resource A.B.C --volume 10
```

Код возврата можно посмотреть сразу после запуска:

```bash
./run.sh --login alice --password qwerty --action read --resource A --volume 10
echo "exit code: $?"
```

Справка:

```bash
./run.sh --help
```

или

```bash
./run.sh -h
```

### Поддерживаемые аргументы

| Короткий | Длинный      | Описание                                              |
|----------|--------------|-------------------------------------------------------|
| `-l`     | `--login`    | Логин пользователя                                    |
| `-p`     | `--password` | Пароль пользователя                                   |
| `-a`     | `--action`   | Действие над ресурсом: `read`, `write`, `execute`     |
| `-r`     | `--resource` | Путь до ресурса, сегменты разделены точками           |
| `-v`     | `--volume`   | Запрашиваемый объём ресурса (целое положительное)     |
| `-h`     | `--help`     | Показать справку                                      |

## Тестирование

```bash
./test.sh
```

Скрипт последовательно запускает программу по одному кейсу на каждый
код ответа, сравнивает фактический код с ожидаемым и печатает
`OK` или `FAIL` для каждого кейса, а в конце — итоговое количество
успешных тестов.

Ожидаемый результат:

```
10/10 успешных тестов
```

---

## Коды ответа

| Описание                                | Код ответа |
|-----------------------------------------|------------|
| Успешное выполнение                     | 0          |
| Запрошена справка                       | 1          |
| Неверный пароль                         | 2          |
| Неверный логин                          | 3          |
| Неизвестное действие над ресурсом       | 4          |
| Нет доступа                             | 5          |
| Несуществующий ресурс                   | 6          |
| Некорректный формат ресурса или объёма  | 7          |
| Превышение максимального объёма         | 8          |
